    Interface ComponentMap

    ComponentMap: the typed DI graph for manifest authoring.

    The base interface is intentionally empty. Slots are added by declaration merging, from this package and from downstream packages such as @o3co/auth-provider-redis:

    declare module "@o3co/auth-provider-core" {
  interface ComponentMap {
    readonly mySlot: MyType;
  }
}

    Grep declare module "@o3co/auth-provider-core" for the slot list (config and pathResolver are in boot/types.mts). Consumers MUST namespace their own keys (e.g. acme.cacheClient) to avoid colliding with o3co slot names.
