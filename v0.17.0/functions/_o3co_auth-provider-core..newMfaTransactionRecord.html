    Function newMfaTransactionRecord

    • newMfaTransactionRecord(tx: MfaTransaction): MfaTransaction

      The record a store keeps for a new transaction, or a RangeError. Every field is held to its type (patch fields by the patch rules, enrollment and emailProof required), attempts must be 0, and version a safe non-negative integer: a limit is only as good as the count it starts from (with attempts NaN, NaN + 1 > max is false and every reservation passes). Only a transaction's fields are kept, sub-objects copied to known fields. Every adapter calls it in create, beside its own expiry check.
