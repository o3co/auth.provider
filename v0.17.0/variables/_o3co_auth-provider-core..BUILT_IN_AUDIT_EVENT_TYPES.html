    Every audit-event type the bundled packages emit, pinned against the emission sites in both directions by audit/__tests__/auditEventInventory.drift.test.mts: an emission missing here, or a name here with no emission left, fails CI.

    Names are dot-separated segments, most specific last, snake_case within a segment: two for a plain subject-and-outcome (authorize.granted, rate_limit.unavailable), more when the subject is namespaced (federation.token.family_revoked, token.issued.failure). Consumers MAY emit custom event types; namespace them so they cannot collide with future entries here.
