    What a module's section adds to its factories' deps:

    • no section (S is never): nothing, so reading deps.section does not compile;
    • a section: readonly section, typed as the schema's output;
    • the widest schema (SectionSchema, the erased Module): section: never, which lets defineModule return Module. A schema typed as plain z.ZodType gets this too; give it its own type (z.object(…)) to read it.
