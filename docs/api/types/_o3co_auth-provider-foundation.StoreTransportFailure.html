    What went wrong with the exchange, when it was not the Store's answer.

    Type Declaration

    • "unreachable"

      No connection to exchange on: refused, DNS, TLS, a route or host the network cannot reach. The network path, or TLS to the Store.

    • "connection_closed"

      A connection that closed — or was reset — before a complete response arrived: before any byte, after an interim 1xx, mid-head, or a pooled keep-alive connection the Store, a proxy or an idle timeout closed between two requests. The transport cannot tell which, so this says no more than that; it is not the network path, and not a malformed answer.

    • "malformed_response"

      The Store (or whatever answers at the URL) sent a response head the transport cannot take: the parser refused the status line or a header, or the head outgrew the size limit. The Store's answer, or a proxy's.

    • "unreadable"

      An HTTP answer arrived, and its body broke before it was read.
