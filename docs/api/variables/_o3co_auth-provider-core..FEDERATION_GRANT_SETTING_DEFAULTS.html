    The defaults config/reference.conf ships, in the units it writes them.

    Exported because a hand-built configuration never passes through that file, and a second copy of these numbers inside a module would be the one that is forgotten. settings.test.mts reads the block back out of reference.conf and compares it to this, so the two cannot drift.
