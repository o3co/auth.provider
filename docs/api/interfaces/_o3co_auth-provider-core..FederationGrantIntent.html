    Interface FederationGrantIntent

    What a backend lodged, and what every later step is judged against (D6).

    Immutable: the callback must decide against what the client asserted and the user was shown, not against configuration as it stands minutes later. The connection's revisions are pinned here for that reason, and the callback refuses when they have moved.
