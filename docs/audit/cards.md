# Module cards

Generated by `references` from each workspace package's card and manifest: do not edit; run `pnpm --filter @mod/references run configuration`.
Each workspace package, by the directory under `modules` it lies in, with its kind, its directory and the line its card opens with; its internal modules beneath it, each by its directory within the package. A card is the `README.md` of the directory named.

## audit-receivers

- `@mod/audit-http` (adapter, `modules/audit-receivers/audit-http`): Contributes the audit receiver `http` to `audit`, posting each event to the operator's URL through `outbound`.
- `@mod/audit-stdout` (adapter, `modules/audit-receivers/audit-stdout`): Contributes the audit receiver `stdout` to `audit`, writing each event as one line of JSON on standard output.

## cert-binding

- `@mod/mtls` (feature, `modules/cert-binding/mtls`): Binds tokens to the client's certificate (RFC 8705), as a binding kind of `sender-binding`.
  - `pki` (`src/pki`): Validates a client certificate's path to the anchors. Knows no feature.
  - `revocation` (`src/pki/revocation`): Checks the revocation of every certificate on a validated path but the anchor, by CRL, OCSP or both.

## delegation

- `@mod/federation-grants` (feature, `modules/delegation/federation-grants`): Takes a confidential client's intent to act for a user at one connection, and owns its steps through the browser and upstream, which a browser half runs over `grantIntents`.
  - `api` (`src/api`): the client routes, and the revocation follower.
  - `grant` (`src/grant`): what a grant and a browser step are, and the judgments the other internal modules share.
  - `intents` (`src/intents`): a grant's intent through the browser, as the package owns it.
  - `refresh` (`src/refresh`): handing a grant's upstream token, and renewing it.
  - `sweep` (`src/sweep`): erasing the credentials of grants no request reads.
- `@mod/federation-grants-connect` (feature, `modules/delegation/federation-grants-connect`): Joins `federation-grants`: runs its browser half, the link a client sends the user to, the question, the user's decision and the upstream's callback, over the intents federation-grants owns (`grantIntents`).
  - `connect` (`src/connect`): the browser half of a connection.
  - `upstream-account` (`src/upstream-account`): whose upstream account a connection reached.

  - `gate` (`src/gate`): the gate `credential-policy`.

  - `routes` (`src/routes`): the options route and the login route, up to the assertion.

Records of both spaces changed as one (`updateTogether`) are `records`' records of two places changed as one, one batch across both spaces, so boot is refused where the store writes no records of two partitions as one. The wiring only maps, with no branches or loops. The spaces keep the names webauthn's records had, so the passkeys kept read as they are. Depends on `kernel`, `passkeys`, `records` and `store`.
