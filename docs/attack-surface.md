# Attack surface

Generated by `references` from the full template with every opt-in, on its defaults and the trial's settings, and from the hand-written coverage in `modules/tooling/references/src/attack-surface/coverage.ts`: do not edit; run `pnpm --filter @mod/references run configuration`.
It is one composition, not every one: a module another composition adds opens what its card says. A list here is read from what modules declare, and a declaration is its owner's claim, not a proof.

## What this composition leaves out

Packages with a module the full template with every opt-in does not compose: `@mod/audit-stdout`, `@mod/mail`, `@mod/store`.

## Routes

54 routes (GET 21, POST 33); each is in [the route reference](routes.md).

- `HEAD` is answered for each `GET` that does not change state (15 of them), and for no other: a `GET` that changes state is never reached by `HEAD`.
- A CORS preflight (`OPTIONS` with `Access-Control-Request-Method`) is answered for the routes a path reaches that take cross-origin requests.

## Reaching out

A package that depends on `outbound` can reach another server through it; this says who can, not every call or where its destination comes from.

- Packages that speak to the network themselves (`network` in their manifest): `@mod/http` (serves-http), `@mod/mail-smtp` (smtp), `@mod/outbound` (outbound), `@mod/redis` (redis).
- Packages that depend on `outbound`: `@mod/audit-http`, `@mod/client-assertion`, `@mod/clients-cimd`, `@mod/external-jwt`, `@mod/idp-apple`, `@mod/idp-github`, `@mod/idp-google`, `@mod/idp-oidc`, `@mod/jti-ledger-http`, `@mod/jwt-bearer`, `@mod/mfa-witness-http`, `@mod/mtls`, `@mod/passkey-witness-http`, `@mod/rp-logout`, `@mod/signer-keys-http`, `@mod/upstream-client`, `@mod/users-http`.
- Packages that may reach private addresses at URLs of the operator's configuration (`outbound-policy`'s `internalBy`): `@mod/audit-http`, `@mod/external-jwt`, `@mod/idp-github`, `@mod/idp-oidc`, `@mod/jti-ledger-http`, `@mod/mfa-witness-http`, `@mod/passkey-witness-http`, `@mod/signer-keys-http`, `@mod/users-http`.
