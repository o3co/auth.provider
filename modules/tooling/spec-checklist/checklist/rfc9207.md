# RFC 9207: OAuth 2.0 Authorization Server Issuer Identification

## 2 Response Parameter iss

- **rfc9207-2-a** MUST: every authorization response, an error response included, carries `iss`, the server's issuer identifier.
- **rfc9207-2-b** MUST: the `iss` value is an https URL with no query and no fragment.
  note: N-https

## 2.3 Providing the Issuer Identifier

- **rfc9207-2.3-a** MUST: the server provides its issuer identifier to clients.
- **rfc9207-2.3-b** MUST: the metadata's `issuer` is identical to the `iss` the authorization responses carry.
- **rfc9207-2.3-c** MUST: the metadata says `authorization_response_iss_parameter_supported` is `true`.

## 2.4 Validating the Issuer Identifier

- **rfc9207-2.4-a** MUST: where an ID token comes back from the authorization endpoint, the `iss` parameter is identical to its `iss` claim.
  out-of-scope: no ID token comes back from the authorization endpoint (`response_types_supported` is `code`).
