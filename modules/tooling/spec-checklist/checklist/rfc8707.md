# RFC 8707: Resource Indicators for OAuth 2.0

## 2 Resource Parameter

- **rfc8707-2-a** MUST: a `resource` that is not an absolute URI is refused, never issued as an audience.
- **rfc8707-2-b** MUST NOT: a `resource` that carries a fragment is taken, or issued as an audience.
- **rfc8707-2-d** MUST: a `resource` o3co's client sends an upstream is an absolute URI: `federation-grants` reads `connections.<name>.resource` as a URL and refuses the boot otherwise.
  role: client
- **rfc8707-2-e** MUST NOT: a `resource` o3co's client sends an upstream carries a fragment.
  role: client
  noncompliant: `federation-grants` reads `connections.<name>.resource` with `z.url()`, which takes a URL with a fragment, and the value is sent upstream as written; whether to refuse one at boot or record a deviation is the owner's decision.
- **rfc8707-2-c** SHOULD: an access token issued for a `resource` is audience-restricted to it, by that value or a more general identifier it maps to.
