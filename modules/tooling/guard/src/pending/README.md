# pending

## Responsibilities
- Measures the limits still to come and reports each place over one, refusing nothing, so that new overruns are seen while the cards over them are deepened.

## Not here
- Refusing: a limit becomes a G7 limit of the package once nothing is over it.
- Lists of the places over a limit: each run measures the repository as it is.

## Offers
- `pendingLimits(packages, budget)`: each place over a limit, by where and what went over.

## Invariants
- A card many depend on at run time is held to `narrowCardBytes`.
- Every card item, a line opening with `- ` (nested ones too), is held to `cardItemBytes`; the report names its opening.
- A unit's test lines count its `test/fixtures` (`countedFixtureFile`) against `testLines`; other test tables, such as vectors, still count for nothing.

## Depends on
- None (guard's own units and line counts)
