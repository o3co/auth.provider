# account-erasure-store

Wires `account-erasure`'s maintenance interface, `erasureMaintenance`, to the store: each member onto its one counterpart in `storeUpkeep` or `storeControl`, the phase onto `subject-records`' `subjectRecordsPhase` (`read`; `writeWith`, handed the upkeep's own mark write). Each of store's answers is a plain copy (`structuredClone`), typed as account-erasure's own, `sweep`'s keys included, which erasure hands on unread for an eraser to hand back; this is the only place store's types become erasure's, the words staying the same where they mean the same. Both contracts are required, so a store offering no control record refuses the boot. `store` is taken only to hand to `subjectRecordsPhase.writeWith`, which asks whether it pairs. The wiring only maps, with no branches or loops. Depends on `kernel`, `account-erasure`, `store` and `subject-records`.
