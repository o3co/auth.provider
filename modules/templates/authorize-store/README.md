# authorize-store

Wires `authorize`'s store interface, re-authentications, and `reauth`'s, which takes it over, both to the one space of `records`' records under a secret, so a re-authentication's name never reaches the store. Its one space declares a guarantee for each need `authorize` states. A need with nothing mapped to it, a guarantee or records under a secret, fails the type check, and `authorize`'s store contract, run on a store that loses what a missing guarantee allows, checks what each guarantee means. The wiring only maps, with no branches or loops. Depends on `kernel`, `authorize`, `reauth`, `records` and `store`.
