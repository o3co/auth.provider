# authorize-store

Wires `reauth`'s store interface, re-authentications, to `records`' records under a secret, so a re-authentication's name never reaches the store. Its one space keeps the name it had when `authorize` held these records, so records written before an upgrade are found after it. The space declares a guarantee for each need `reauth` states. A need with nothing mapped to it, a guarantee or records under a secret, fails the type check, and `reauth`'s store contract, run on a store that loses what a missing guarantee allows, checks what each guarantee means. The wiring only maps, with no branches or loops. Depends on `kernel`, `reauth`, `records` and `store`.
