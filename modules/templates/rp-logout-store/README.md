# rp-logout-store

Wires `rp-logout`'s store interfaces: the clients of each session to keyed sets on `kernel`'s clock, the 0.19 notices to deferred work, the queue of entries to deferred work in `rp-logout-store.deferred` (no subject's data, `subjectData: none`: each entry a body's id, a digest, and a time), and the notices' bodies to `subject-records` over the phase this process reads once, in `rp-logout-store.notice-bodies`: `online-indexed`, each body created for its subject, fenced at creation by the subject's tombstone, erased by `rp-logout`, beside its index space, declaring `tombstoneFloor`, every port the builder's own. The composition is out of traffic while the phase cannot be read (probe `rp-logout-store.phase`). Each has its own space, which declares a guarantee for each need `rp-logout` states. The operator section sets `clients-per-session` (1–1000, default 64), the cap of each session's set; a session's clients are those that redeemed a code in it, few in practice, and one pushed out over the cap is answered, so `rp-logout` logs it. The 0.19 notices and the queue are each spread over `notice-shards` shards (1–65536, default 64) of up to `notices-per-shard` notices (1–10000, default 1000), and an add to a full shard is refused rather than push one out; a notice stays only while its client cannot be reached, so the defaults, about 64,000, leave room for an outage of some clients. A need with nothing mapped to it fails the type check, and `rp-logout`'s store contract, run (the bodies' in both phases) on a store that loses what a missing guarantee allows, checks what each guarantee means. The wiring only maps, with no branches or loops. The 0.19 notices' space is declared `subjectData: none`, with one bend: the notices a 0.19 instance kept each name a subject, held only until `rp-logout`'s one migration drains them into bodies, which runs before erasure can be enabled; 0.20 never writes there. The clients' space holds no subject's data (`subjectData: none`): a session's handle and the ids of the clients it reached. Depends on `kernel`, `rp-logout`, `records`, `subject-records` and `store`.
