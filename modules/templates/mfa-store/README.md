# mfa-store

Wires `mfa`'s store interface, factor lists, to `records`' records, kept without end, a list and a claim changed as one through `records`' paired records (a store that cannot refuses the boot, as `records` tells it). Its one space declares a guarantee for each need `mfa` states. A need with nothing mapped to it fails the type check, and `mfa`'s store contract, run on a store that loses what a missing guarantee allows, checks what each guarantee means. The wiring only maps, with no branches or loops. Depends on `kernel`, `mfa`, `records` and `store`.
