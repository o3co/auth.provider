# users-store

Wires `users`' store interfaces, links and verified contacts, to `records`' records, kept without end, and the link store's `names` (IdP names' own records, in `users-store.names`, declared as holding no subject's data) and `unowned` (a name's record kept raw in the link space, deprecated from birth), offered together. Each interface has a space of its own, which declares a guarantee for each need `users` states for it. A need with nothing mapped to it fails the type check, and `users`' store contracts, run on a store that loses what a missing guarantee allows, check what each guarantee means. The wiring only maps, with no branches or loops. Depends on `kernel`, `users`, `records` and `store`.
