# webauthn-store

Wires `passkeys`' store interfaces to `records`. Passkeys are records kept without end in two spaces, one for credentials and one for subjects, each declaring a guarantee for each need `passkeys` states for them. Challenges are records under a secret, so a challenge never reaches the store, in a space declaring the other needs. A need with nothing mapped to it fails the type check, and the store contracts, run on a store that loses what a missing guarantee allows, check what each guarantee means. The wiring only maps, with no branches or loops. The spaces keep the names webauthn's records had, so the passkeys kept read as they are. Depends on `kernel`, `passkeys`, `records` and `store`.
