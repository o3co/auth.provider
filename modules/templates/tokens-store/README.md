# tokens-store

Wires `tokens`' store interface, revoked tokens, to `records`' records. Its one space declares a guarantee for each need `tokens` states. A need with nothing mapped to it fails the type check, and `tokens`' store contract, run on a store that loses what a missing guarantee allows, checks what each guarantee means. The wiring only maps, with no branches or loops. Depends on `kernel`, `tokens`, `records` and `store`.
