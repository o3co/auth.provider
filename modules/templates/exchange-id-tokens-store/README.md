# exchange-id-tokens-store

Wires `exchange-id-tokens`' store interface, the id_tokens taken by kind and name, to `records`' records, each kept for the lifetime `exchange-id-tokens` gives. Its one space declares a guarantee for each need `exchange-id-tokens` states. A need with nothing mapped to it fails the type check, and `exchange-id-tokens`' store contract, run on a store that loses what a missing guarantee allows, checks what each guarantee means. The wiring only maps, with no branches or loops. Its space is pseudonymous (`subjectData: pseudonymous`): a digest over the ID token's signed part, recomputable from the subject with its issuer, audience and times where the token has no nonce, kept until the token's expiry and clock allowance; erasure leaves it to expire. Depends on `kernel`, `exchange-id-tokens`, `records` and `store`.
