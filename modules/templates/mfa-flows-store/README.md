# mfa-flows-store

Wires `mfa-flows`' store interfaces to `records`: transactions to records under a secret, so a transaction's identifier never reaches the store, and each holder's transaction listings to keyed sets of up to `transactionsPerHolder` (5) on `kernel`'s clock, whose members are digests, so no secret names them. Each has its own space, declaring a guarantee for each of the other needs `mfa-flows` states; the listings' declares confirmed reads, so the store answers them only from writes a failover keeps. A need with nothing mapped to it fails the type check, and `mfa-flows`' store contracts, run on a store that loses what a missing guarantee allows, check what each guarantee means. The wiring only maps, with no branches or loops. Depends on `kernel`, `mfa-flows`, `records` and `store`.
