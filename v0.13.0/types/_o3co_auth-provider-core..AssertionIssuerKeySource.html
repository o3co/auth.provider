    Where an issuer's signing keys come from (#525).

    • key — one public key, held in memory. The shape createJwtAssertionVerifier has always taken; rotation means re-registering.
    • jwks — a static JSON Web Key Set, for an issuer that publishes several keys but no endpoint.
    • jwks_uri — a remote JWKS endpoint, fetched on first use and cached. An unknown kid triggers a refetch (bounded by cooldownMs), which is how a rotation at the issuer is picked up without a restart. https is required unless the host is loopback: signing keys fetched over plaintext are keys an on-path attacker chose.
