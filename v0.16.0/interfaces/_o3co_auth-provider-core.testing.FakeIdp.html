    authorize

    • authorize(url: string | URL): FakeIdpAuthorizationResponse

      Play the user agent and the user at the authorization endpoint: accept the authorization request url names (its client, redirect URI, PKCE challenge and nonce are recorded, and that code's id_token echoes that nonce), approve it, and answer what the IdP redirects back with. The token endpoint then holds the exchange of that code to the recorded request: the same redirect URI, a verifier that matches the challenge, one use — a second exchange is invalid_grant.
