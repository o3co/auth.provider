    Interface DelegatedCodeExchangeRequest

    What the connect callback asks of an adapter (#593, D7, D17): exchange the code the upstream sent back for the grant's first tokens, and say whose they are.

    Not the login flow's exchangeCode. That one answers a login profile — it may call UserInfo, map claims, and fill a lifetime the upstream never sent — and it has no place for three things an acquisition needs: the RFC 8707 resource at the token endpoint, the lifetime the upstream SENT rather than what a library coerced it to, and a per-call signal for the callback's time budget.
