    OptionalallowPublicClients

    allowPublicClients?: boolean

    Whether tokenEndpointAuthMethod === "none" (public) clients are accepted on this route. Defaults to false because the only routes that can soundly admit them are /oauth/token (where PKCE/S256 is the authenticity gate, enforced separately at /oauth/authorize).

    RFC 7662 §2.1 requires that introspection callers be authenticated; accepting a public client there would let anyone who knows a client_id (a non-secret value) query token metadata. Routes other than /token MUST leave this option at the default.
