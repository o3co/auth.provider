    onBuilt

    • onBuilt(hook: () => void | Promise<void>): void

      Runs hook once every build passed, in the order registered, each awaited, before assemble answers: for what a boot may write only once no module refuses it. It uses what its factory holds; a late reference and readiness do not answer yet. A refuse, or any throw, refuses boot as a build's does, and the hooks after it do not run; what an earlier hook wrote is not taken back.
