    Zod schema markers for HOCON unit values. Each reads the forms the matching Config getter reads and gives what the getter gives (a number in the requested unit, or a Period); pipe it into a schema for the constraints:

    const Session = z.object({
      lifetime: hocon.duration('s').pipe(z.number().int().min(60)),
      maxBody: hocon.bytes().pipe(z.number().int().positive()),
    })
